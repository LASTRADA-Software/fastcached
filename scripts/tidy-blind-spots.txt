# Translation units that contribute NOTHING on the platform a given clang-tidy leg
# runs on, and which OTHER leg (if any) does read them.
#
# **"Blind" is a property of (unit, set of legs), not of a unit.** A unit inside
# `#if defined(_WIN32)` is empty on Linux and real on Windows, so whether anything
# analyses it depends on which legs exist -- and the answer changes when a leg is
# added. The middle column is therefore a LIST of legs, and `none` means exactly
# that: no analyser this project runs reads this unit.
#
# `scripts/check-tidy-blind-spots.sh` MEASURES the blind set for the build it is
# given and refuses when this table disagrees, in either direction. It also refuses
# a row naming a leg that does not exist in `.github/workflows/build.yml`, so a leg
# that is deleted or renamed cannot leave rows quietly claiming coverage. The list
# is never the evidence -- the measurement is.
#
# The count of units reached by NO leg is printed on every run, and deliberately not
# restated here: a figure in prose beside the table it describes is a second claim, and
# this one went stale the first time a row was added. It is two kinds of unit, and the
# reason column says which: the kqueue units, reached by nothing until a macOS leg exists
# (https://github.com/LASTRADA-Software/fastcached/issues/858), and the instruction-set
# probe, which holds no code for ANY analyser to read on any platform (#1447).
#
# Format: <path><TAB><reached-by, comma-separated, or `none`><TAB><reason>
